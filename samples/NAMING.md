# サンプル音声の命名規則

加工音声は次の順序で命名する。区切りは二重アンダースコア `__`。

`音源__サンプリング周波数__構成__条件.flac`

原音は `音源__サンプリング周波数__reference.flac` とし、符号化方式や仕様世代を付けない。

| 項目 | 表記と意味 |
|---|---|
| 音源 | `demo`、`fishin`、`vibeace`、`hires_probe` |
| サンプリング周波数 | `32k`、`48k`。音声帯域を表す値ではない |
| 構成 | プロファイル名。2系統は `主系+副系`。アナログFMは `FM` |
| コーデックのみ | `codec`：通信路なし |
| 理想通信路 | `ideal`：雑音なしの実シンボル送受信 |
| 白色雑音 | `awgn-cn0-66dBHz`：C/N0が66 dB-Hz。C/NやEs/N0ではない |
| フェージング | `rayleigh-cn0-60dBHz`、`main-fade-10dB-cn0-66dBHz` |
| 位相のみの比較 | `phase-only-awgn-cn0-66dBHz`。構成欄の副系も送信する |

例：

- `fishin__32k__reference.flac`：32 kHzの原音。
- `fishin__32k__B200M+SUB50M__awgn-cn0-57dBHz.flac`：現行仕様のモノラル主系＋副系、白色雑音条件。
- `demo__48k__M700Y__ideal.flac`：現行仕様M700Y、雑音なしのシンボル送受信。
- `demo__48k__M700Y__codec.flac`：現行仕様のコーデック単体音声。

`M700-base` は実際の基本層を保持し、拡張層だけ不明として復元する比較条件、`M700Y-R10` / `R12` はY仮数幅10 / 12 bitの比較条件。登録プロファイルとは区別する。

保存場所は、32 kHzの主系・副系音声がこのディレクトリ、48 kHzは `monitor/`、Y系は `hybrid_y/` と `monitor_y/`。同じ原音が各評価フォルダに複製されている場合は同じ名前を使う。

生成ツールは `tools/sample_names.py` の共通関数で命名する。旧版の音声・試聴ページ・改名対応表は保持せず、履歴はGitで管理する。現行音声の全設定・保存後の波形SNR・SHA-256は [音源一覧JSON](../docs/results/samples.json) に記録する。名前は主要条件を示すものであり、乱数seed・電力配分・全設定は評価JSONを参照する。
