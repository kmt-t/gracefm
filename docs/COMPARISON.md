# GraceFM と FM・aptX・DAB+ の比較（現行設定）

比較の基準は GraceFM の現行設定。32 kHz の放送用主系は 99% 占有帯域を約180 kHz に調整した。以下の数値はシミュレーションとコーデック評価であり、実機・実電波の測定値ではない。

## アナログ FM：通信路を含む比較

同じ32 kHzモノラル原音を10秒ずつ使い、GraceFM `B200MH+S50M`（主系・副系の送信電力50:50）とアナログ FM を同じ直接波 C/N0 で評価した。同期既知のシミュレーションで、各セルは原音に対する保存済みFLACの波形 SNR（dB）。[個々の音源と条件・ハッシュ](results/samples.json)を参照。

| 素材 | C/N0 dB-Hz | GraceFM | FM |
|---|---:|---:|---:|
| fishin | 54 | 10.77 | 4.02 |
| fishin | 60 | 22.42 | 24.07 |
| fishin | 66 | 32.48 | 38.16 |
| fishin | 80 | 55.27 | 51.16 |
| vibeace | 54 | 13.60 | 2.81 |
| vibeace | 60 | 29.50 | 22.85 |
| vibeace | 66 | 44.48 | 36.62 |
| vibeace | 80 | 68.33 | 50.66 |

素材と受信条件によって優劣が変わる。波形 SNR だけで聴感上の優劣は決められない。FM は既存のアナログ受信機を使えるが、GraceFM のデータは専用復調器が必要。

## aptX / aptX HD：コーデック単体の比較

3素材を各5秒、同じピーク値で評価した。GraceFM は現行 `B200H`、aptX と aptX HD は FFmpeg のコーデック往復。共通16 kHz帯域では全方式に同じ32 kHz化原音を与え、aptX側は48 kHzに再標本化した。ViSQOL MOS-LQO と波形 SNR は各素材・左右チャンネルの平均。通信路、Bluetooth のペアリング・再送・バッファ遅延、GraceFM のRF通信路は含まない。[素材別の全測定値](results/aptx_benchmark.json)を参照。

| 評価帯域 | 方式 | 音声ビットレート kb/s | ViSQOL 平均 | 波形 SNR 平均 dB |
|---|---|---:|---:|---:|
| 共通16 kHz | B200H | 512 | 4.411 | 55.50 |
| 共通16 kHz | aptX | 384 | 4.709 | 51.45 |
| 共通16 kHz | aptX HD | 576 | 4.731 | 60.51 |
| 元の48 kHz | B200H | 512 | 3.925 | 52.07 |
| 元の48 kHz | aptX | 384 | 4.703 | 50.29 |
| 元の48 kHz | aptX HD | 576 | 4.731 | 58.95 |

この条件の ViSQOL では aptX 系が上回る。元の48 kHz帯域の比較には、GraceFM B200H の音声帯域上限16 kHzも含まれる。ビットレートは音声データであり、無線フレーム全体の速度ではない。

## DAB+：規格上の位置付け

[ETSI TS 102 563](https://www.etsi.org/deliver/etsi_ts/102500_102599/102563/02.01.01_60/ts_102563v020101p.pdf) によると、DAB+音声は MPEG HE-AACv2 の規定されたサブセットを使い、120 ms の音声スーパーフレームを Reed–Solomon 符号と仮想インターリーブで保護する。[ETSI EN 300 401](https://www.etsi.org/deliver/etsi_en/300400_300499/300401/02.01.01_60/en_300401v020101p.pdf) の DAB 無線信号の公称帯域は1.536 MHz。GraceFM の約180 kHzの単一主系と、DAB の多サービス用の多重信号を帯域だけで同条件とみなすことはできない。

DAB+は比較候補に含めるが、現環境に規格に合う HE-AACv2 エンコーダと DAB+ フレーミング・RFモデルがないため、音質・受信感度・端末間遅延の数値比較は**未測定**。手元の AAC-LC エンコーダによる結果を DAB+ として代用しない。比較するには、同一原音で規格準拠の DAB+ スーパーフレームを生成し、受信機バッファを含む遅延、同一条件のRF通信路、音声復号後の品質を測る。
