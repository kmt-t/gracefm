# GraceFM と FM・aptX・MPEG HE-AAC の比較

方式、フレーム予算、ビットレートと占有帯域は[技術論文](SPEC.md)を参照。以下はオフライン評価であり、実機・実電波の測定ではない。

## アナログ FM：通信路込み

同じ32 kHzモノラル原音を10秒ずつ使い、GraceFM `B200M+SUB50M`（主系・副系の送信電力50:50）とアナログ FM を同じ直接波 C/N0 で評価した。同期既知のシミュレーションで、各セルは保存済みFLACの原音に対する波形SNR（dB）。[個々の音源と条件](results/samples.json)を参照。

| 素材 | C/N0 dB-Hz | GraceFM | FM |
|---|---:|---:|---:|
| fishin | 54 | 9.82 | 4.02 |
| fishin | 60 | 19.18 | 24.07 |
| fishin | 66 | 32.36 | 38.16 |
| fishin | 80 | 55.34 | 51.16 |
| vibeace | 54 | 12.98 | 2.81 |
| vibeace | 60 | 27.65 | 22.85 |
| vibeace | 66 | 41.37 | 36.62 |
| vibeace | 80 | 63.05 | 50.66 |

素材と受信条件によって優劣は変わる。波形SNRだけで聴感上の優劣は決まらない。FMは既存のアナログ受信機を使えるが、GraceFMのデータは専用復調器が必要である。

## 音声コーデック単体：チャンネル数と帯域を一致

評価は各5秒。モノラルはピアノ・打楽器のステレオ音源を `(L+R)/2` に縮約し、元からモノラルのギターを加えた3素材。ステレオは元からステレオのピアノ・打楽器2素材。両者は**別集計**とする。各表は素材ごとのViSQOL Audio MOS-LQOと波形SNRを算術平均した。ステレオViSQOLは左右を測ってから平均した。通信路、FEC、再送、受信バッファは含まない。[素材別結果と実装版情報](results/codec_matched.json)・[再現スクリプト](../tools/eval_codec_matched.py)を参照。

16 kHz表は全方式に同じ48→32→48 kHzで帯域制限した入力を渡し、原音と全復号出力へ同じ帯域制限を再適用して48 kHzで評価した。24 kHz表は48 kHz原音を使い、32 kHzのB200系は含めない。表のGraceFMビットレートは音声データ量であり、ヘッダ・CRC・FEC・プリアンブルを含まない。他方式のビットレートも設定値または規定の音声レートで、無線上の総速度ではない。

### DAB+との関係

[ETSI TS 102 563](https://www.etsi.org/deliver/etsi_ts/102500_102599/102563/02.01.01_60/ts_102563v020101p.pdf) はDAB+にMPEG HE-AAC v2のサブセットを規定する。[DAB+向けODR-AudioEnc](https://github.com/Opendigitalradio/ODR-AudioEnc/blob/master/README.md#dab-aac-encoder-configuration)はステレオ48 kb/s以下で既定でPSを使うため、ステレオ表では32/48 kb/sのHE-AAC v2（SBR+PS）を測った。モノラル表はHE-AAC v1（SBR）である。測定に使ったFDK AACは通常のAAC変換長であり、DAB+が要求する960サンプル変換ではない。DAB+の120 msスーパーフレーム、Reed–Solomon符号、仮想インターリーブ、RF通信路、受信遅延も含めていない。表は**音声コーデック実装**との比較であり、DAB+準拠伝送との比較ではない。
