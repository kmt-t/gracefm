# GraceFM：Haar帯域分割を用いた低遅延デジタル音声伝送

## 要旨

GraceFMは、64サンプルの音声を整数可逆のHaar変換で帯域分割し、帯域別に量子化して無線シンボルへ写像する低遅延デジタル音声伝送方式である。

- **フレーム構造**: FEC付きの**ヘッダ**（ヘッダ・指数・区間アッテネータ・CRC）と、**Haar係数部**（仮数上位bitのパリティと、FECなしの仮数bit）に分ける。高域 H2/H1 には別のCRCを割り当てる。
- **変調方式**: QPSK、強弱のある階層16QAM、および高域M係数を1係数1複素シンボルで送るY方式（QASK）を定義する。
- **受信・出力処理**: 軟判定復号、任意の2周波数系統の帯域別融合、LPCによる連続欠落の補間を行い、出力は 48 kHz/int32 とする（48 kHz系は素通し、32 kHz系は3/2再標本化。5.1節）。
- **拡張プロファイル（`-L`）**: 帯域分割をLeGall 5/3に替え、主系の仮数を一部狭めた `-L` プロファイルも定義する（1.1節）。
- **本書の範囲**: [参照実装](../gracefm/)のアルゴリズムと[計算した設定表](PROFILES.md)を記述する。数値はオフラインシミュレーションであり、実機のRF性能、同期取得、法規適合性を示すものではない。

## 1. 信号モデルと帯域

- **入力とM/S変換**: サンプリング周波数 $`f_s=32`$ または $`48`$ kHzの左右PCMを入力とし、$`M=(L+R)/2`$、$`S=(L-R)/2`$ に変換する（モノラルプロファイルは $`M`$ のみ送信）。
- **フレーム周期**: 1フレームは64サンプル。フレーム周期は $`T_f=64/f_s`$（32 kHzで 2 ms、48 kHzで約 1.333 ms）。音声ブロック内に先読みはない。
- **実装**: [codec.py](../gracefm/codec.py) が変換と量子化を実装する。

### Haar帯域分割

偶数・奇数の組ごとに整数可逆のS変換（$`d=x_{2i+1}-x_{2i}`$、$`a'=x_{2i}+\lfloor d/2\rfloor`$）を、最低域の帯域幅 $`f_s/2^{L+1}`$ が 2 kHz を下回る最小の段数 $`L`$ だけ繰り返す。32 kHz・48 kHzともに $`L=4`$ である。

| 帯域 $`k`$ | 種別 | 係数数 | 32 kHz時の帯域 | 48 kHz時の帯域 | 備考 |
|---:|---|---:|---|---|---|
| 0 | 最終近似 | 4 | 0–1 kHz | 0–1.5 kHz | 最低域 |
| 1 | 詳細 | 4 | 1–2 kHz | 1.5–3 kHz | |
| 2 | 詳細 | 8 | 2–4 kHz | 3–6 kHz | |
| 3 | 詳細 | 16 | 4–8 kHz | 6–12 kHz | **H2** |
| 4 | 詳細 | 32 | 8–16 kHz | 12–24 kHz | **H1** |

- Haarの帯域は理想的な矩形周波数帯域ではない。
- 帯域分割は**加算とシフトだけ**で記述でき、乗算器を使わない。量子化しなければ、係数から入力の整数を 1 LSB も違わず復元できる（M/Sを作るときの下位 2 bit の丸めは別）。
- 可逆リフティングと正規直交尺度の局所的な SNR 差は [評価結果](EVALUATION.md#41-帯域分割の誤差雑音漏れ最悪利得) を参照。参照実装はこの計算を整数だけで行う（[固定小数点実装](FIXED.md)）。

### 1.1 LeGall 5/3 の帯域分割（`-L` プロファイル）

Haarは1ブロックで完結するが合成基底が矩形であるため、ある帯域の係数に載った伝送路雑音が広い帯域へ広がる。名前の末尾が `-L` のプロファイルは、帯域分割をブロックをまたぐ LeGall 5/3 に替え、主系の一部の帯域の仮数を狭める。

- **リフティング式**: 偶数・奇数の組に対して加算とシフトだけの整数可逆変換を行う（両端は対称折り返し）。
  - $`d_i = x_{2i+1} - \lfloor(x_{2i}+x_{2i+2})/2\rfloor`$
  - $`s_i = x_{2i} + \lfloor(d_{i-1}+d_i+2)/4\rfloor`$
- **ブロック構成**: 段数と各ブロックの係数数はHaarと同じ。ストリーム全体の変換結果を64サンプルぶんずつフレームへ切り分ける。
- **雑音特性**: 正規直交ではないため白色雑音に対する電力利得は帯域で異なるが、低域へ入れた雑音の高域への漏れはHaarより小さい（実測値は [評価結果](EVALUATION.md#41-帯域分割の誤差雑音漏れ最悪利得)）。

**ブロックをまたぐことによる制約**:

- **遅延**: 送信側はブロック終端の15サンプル先まで待ってから符号化する。受信側はフレームの係数がブロック先頭の15サンプル前まで影響するため、その分だけ出力を遅らせる。合計30サンプル（32 kHzで約 0.94 ms、48 kHzで 0.625 ms）増える（6節）。段数 $`L`$ では各 $`2^L-1`$ サンプル。
- **欠落の広がり**: 1フレームの係数はブロックの前15サンプルと後16サンプルにも影響する。欠落時は、その範囲を含む95サンプルを無効にしてPLCで埋める。
- **融合**: 主系と副系は同じ帯域分割にそろえる（`-L` の主系には `-L` の副系）。PCMへ戻さず、復号した係数のまま融合してから合成する（5.2節）。
- **格子**: 2系統のブロックの格子は一致させる（時刻のずれ 0）。

**識別と仮数幅の削減**:

- **ヘッダ識別**: プロファイルIDはHaarと共通で、形式識別子（3節）で区別する。IDの予約を消費しないため全11プロファイルに対応する `-L` がある（リンク評価は [評価結果 3節](EVALUATION.md#3-legall-53-lと-haar-の比較)）。
- **仮数幅の削減**: 5/3では伝送路雑音が広がりにくいため、主系の `-L` は以下の帯域でHaarより仮数を4 bit（係数あたり1シンボル）狭める。副系の `-L` はHaarと同幅。結果として `-L` の音声量とシンボル数はHaarより小さい（選定根拠は [評価結果 4.2節](EVALUATION.md#42--l-仮数幅削減の選定根拠)）。

| 対象 | 帯域 $`k`$ | 仮数幅の変化 | 基本層の変化 |
|---|---|---|---|
| 全主系 `-L` | $`k=1`$ | 11 → 7 bit | 5 → 3 bit |
| M700-L（Mのみ） | $`k=4`$ | 7 → 3 bit | 3 → 1 bit |

## 2. 帯域別の量子化と音声データ量

各成分・帯域の仮数幅 $`b_{c,k}`$ と共有指数幅はプロファイルで固定する。

- **仮数幅の制約**: 上位 $`K`$ bitのパリティ（$`K`$ bit）と合わせて2の倍数になる値にする。$`K=1`$ なら奇数となり、現行の主系は最低域（$`k=0`$）が $`K=2`$ の 10 bit、他帯域が $`K=1`$ の 11/7/3 bit、QPSK副系は 7〜3 bit を使う。階層16QAMでは位相部（基本層の仮数＋パリティ）と振幅部（拡張層）をどちらも2の倍数にする（3.2節）。
- **量子化式**: 係数 $`x_{c,k,j}`$ の量子化値 $`m_{c,k,j}`$ は次式で求める。
```math
m_{c,k,j}=\text{clip}\!\left(\text{round}\!\left(\frac{x_{c,k,j}}{2^{e_{c,k}-a_{c,k,j}}}\right),q_{\min},q_{\max}\right),\qquad q_{\max}=2^{b_{c,k}-1}-1.
```
- **区間アッテネータ** $`a_{c,k,j}\in\{0,1\}`$: 1なら量子化刻みを半分にする（RF出力電力を下げる機能ではない）。全登録プロファイルの送信成分に少なくとも1区間を持たせる。
- **共有指数**: 指数は帯域内で共有し、整数の指数インデックス $`e-e_{\min}`$ を送る。送信機はピークから決めた指数とその1段下の候補について、区間ごとにアッテネータ 0/1 を選び、二乗誤差が小さい組を採用する。
- **仮数範囲**: 通常は $`[-q_{\max}, q_{\max}]`$、Y高域だけは負端に1値多い範囲を使う。

**1フレームの音声データ量 $`P`$ と名目ビットレート $`R_{\rm audio}`$**:

```math
P=\sum_{c,k:b_{c,k}>0}\left[E_{c,k}+A_{c,k}+n_k b_{c,k}\right],\qquad R_{\rm audio}=P\frac{f_s}{64}.
```

- $`E_{c,k}`$：指数bit数、$`A_{c,k}`$：区間アッテネータbit数、$`n_k`$：係数数。
- $`R_{\rm audio}`$ は量子化表現の名目ビットレートであり、ヘッダ、CRC、FEC、プリアンブル、詰め物を含まない。
- Y方式の高域仮数も8 bit表現として数えるが、その非保護部分はデジタルbit列ではなく専用シンボルの半径へ写像する。帯域別の全幅、指数、区間長は [設定マトリクス](PROFILES.md) を参照。

## 3. フレームフォーマットと誤り訂正

1音声ブロックが1無線フレームに対応する。誤り訂正は、位相部（階層16QAMの強い2位置）にパリティ、振幅部（弱い2位置）にデータを置く**系統符号**に統一する。1シンボルが「パリティ2 bit｜データ2 bit」となり、FEC付きの部分も強弱の位置を使い切る。

- **系統符号の仕様**: $`(133,171)_8`$ の符号語集合を、情報bit $`x`$ を第1系列とする再帰形で使う（実装：[fec.py](../gracefm/fec.py)）。
  - 入力: $`u_t = x_t \oplus u_{t-2} \oplus u_{t-3} \oplus u_{t-5} \oplus u_{t-6}`$
  - パリティ（第2系列）: $`c_{1,t} = u_t \oplus u_{t-1} \oplus u_{t-2} \oplus u_{t-3} \oplus u_{t-6}`$
- **終端**: 情報bit $`n`$ 個に対し、パリティ $`n+6`$ bit と終端の情報bit 6 bit を送る（ゼロ入力 $`u`$ を6回続けて状態を0に戻す）。
- **復号・因果性**: 受信側はデータとパリティの軟値を同じ尺度の対数尤度比（LLR）で合わせ、軟判定ビタビで復号する。パリティは因果的で、先頭 $`m`$ bitのパリティは先頭 $`m`$ bitだけで決まる。

```text
フレーム:   プリアンブル16シンボル | ヘッダ | 終端 | 係数 | 詰め物 | Y高域Mの専用シンボル※
            位相部（強い2位置）: ヘッダのパリティ n+6 | 終端のパリティ 6（+Y用 6）| 係数ごとに [パリティ K | 基本層の仮数]
            振幅部（弱い2位置）: ヘッダの情報 n  + 終端 6 | 終端の情報 6（+Y用 6）| 係数ごとに [拡張層の仮数]
※ 該当帯域・方式にだけ存在する。QPSKは位相部・振幅部の区別がなく、同じ順に並べるだけ。
```

### ヘッダとCRC

ヘッダの情報bitは、**ヘッダ（24 bit、暗号化時は32 bit）→ 指数 → 区間アッテネータ → 基本CRC（12 bit）→ 高域CRC（10 bit※）**の順に並ぶ（定義：[framing.py](../gracefm/framing.py)）。指数とアッテネータは M→S、低域→高域の順。

| ヘッダ項目 | bit幅 | 備考 |
|---|---:|---|
| プロファイルID | 4 | ID 0、12〜15は予約 |
| 系統ID | 1 | |
| 暗号化フラグ | 1 | |
| 形式識別子 | 2 | 帯域分割を示す固定値（Haar: `11`、LeGall 5/3 `-L`: `10`）。世代番号ではない |
| フレーム番号 | 16 | 暗号化時は24 bit（ヘッダ計32 bit） |

| CRC種別 | 多項式・初期値 | 検査範囲 | 備考 |
|---|---|---|---|
| **基本CRC**（12 bit） | `0x80F`、全bit 1、MSBから計算 | ヘッダ、$`k=0\ldots2`$ の指数・アッテネータ、同帯域の仮数上位 $`K`$ bit（Yの $`k=2`$ 最上位bit含む） | |
| **高域CRC**（10 bit） | `0x233`、全bit 1、MSBから計算 | $`k=3,4`$ の指数・アッテネータ、同帯域の仮数上位 $`K`$ bit、Y帯域（$`k\ge 3`$）の最上位bit | 高域を送らないプロファイルには付与しない |

CRCはヘッダと係数のパリティを復号した後に確認し、上位 $`K`$ bitは訂正後の値を使う。

### 係数・終端・スクランブル・暗号化

- **係数の並びと配置**: すべての仮数bitを成分 M→S、帯域 低→高、係数 先頭→末尾の順に並べ、各係数をシンボル単位で分ける。
  - **位相部**: 係数先頭側のシンボルの位相部に、上位 $`K`$ bitのパリティ $`K`$ bitと基本層の仮数bit（rankの小さい順）をパリティ・データの順に1 bitずつ交互配置する（どちらかが尽きたら残りを続ける。$`K=1`$ なら最上位bitがパリティの隣に入る）。
  - **振幅部**: 拡張層の仮数bit（rankの小さい順）を置く。
- **パリティ保護幅 $`K`$**: 各係数の上位 $`K`$ bit（基本層の先頭）のみを保護する。現行の主系は最低域（$`k=0`$）が $`K=2`$、他帯域が $`K=1`$、副系は全帯域 $`K=1`$。仮数下位bit自体にFEC・CRCは付けない。
- **Y方式の高域M**: この列に含めず、専用シンボルの位相に最上位bitとパリティを載せる（4節）。
- **終端**: 情報bitは振幅部、パリティbitは位相部に置き、ヘッダ・係数・Y帯域のそれぞれに6 bitずつ付与する（Y無しなら2組）。
- **スクランブル**: 送信列は `16シンボル既知プリアンブル | デジタルシンボル | Y専用シンボル（Y系のみ）` の順。位相部と振幅部は同じ長さの偶数にそろえ（足りない側を末尾0埋め）、詰め物を含めて PRBS `1+x^14+x^15` でスクランブルする。Y部は別の3 bit/係数のマスクを使う。
- **暗号化（任意）**: 暗号化時は、ヘッダ以外の内容と仮数bitを AES-128-CTR のキーストリームとXORし、暗号文にCRCとパリティを適用する。Y系の暗号化、鍵共有、認証は参照実装の対象外。

### 3.1 ビットからシンボルへの予算

位相部の列の長さを $`N_P`$、振幅部の列の長さを $`N_W`$ とすると、デジタルシンボル数は $`N_d=\lceil\max(N_P,N_W)/2\rceil`$（QPSKでは $`N_d=\lceil N_{\rm tx}/2\rceil`$）、1フレームの総シンボル数とシンボルレートは次式で与えられる（実装：[modem.py](../gracefm/modem.py)、[encoder.py](../gracefm/encoder.py)）。

```math
N_f=16+N_d+N_Y,\qquad R_s=N_f\frac{f_s}{64}.
```

- **Y専用シンボル数 $`N_Y`$**: 通常方式は 0、B200MY/M700MY（MのみY）は 56、B200Y/M700Y（MとSをY）は 112。
- **デジタル変調位置の総速度**: $`R_{\rm slots}=mN_df_s/64`$ bit位置/s（$`m=2`$：QPSK、$`4`$：階層16QAM）。ヘッダ、パリティ、詰め物を含み、プリアンブルとY専用シンボルを含まない（正味の音声ビットレートではない）。

**計算例（B200M）**:

- 音声データ量: $`P=508`$ bit/フレーム → $`R_{\rm audio}=254`$ kb/s
- ヘッダ（CRC込）: 78 bit → $`(78+6)/2=42`$ シンボル
- 上位bit終端: 3シンボル
- 係数（64個）: 136シンボル（位相部・振幅部が各272 bit）
- 合計: デジタル 181シンボル ＋ プリアンブル 16シンボル ＝ **197シンボル/フレーム**（$`R_s=98.5`$ ksym/s）

### 3.2 基本層・拡張層の配分

係数をシンボル単位で分ける際、位相部（強い2位置）の仮数bitを**基本層** $`a`$、振幅部（弱い2位置）の仮数bitを**拡張層** $`e=w-a`$ と呼ぶ（計算：[layers.py](../tools/common/layers.py)、結果：[設定マトリクス](PROFILES.md)）。

- 位相部にはパリティ $`K`$ bitも入るため、$`a+K`$ と $`e`$ をどちらも**2の倍数**にし、係数ごとに $`a+K=e`$ にそろえる。
- $`N`$ シンボルを使う係数の幅 $`w=a+e`$:
  - $`K=1`$ のとき: $`a=2N-1`$、$`e=2N`$、$`w=4N-1`$ bit（現行は 11 / 7 / 3 bit）
  - $`K=2`$ のとき: $`a=2N-2`$、$`e=2N`$、$`w=4N-2`$ bit（最低域は $`N=3`$ で 10 bit）
- ヘッダと終端は位相部・振幅部に同数ずつ入るため、強い位置と弱い位置の差に効かず、詰め物は偶数そろえの高々1個になる。
- Y方式の高域Mは配分対象外であり、Y系ではデジタル部の弱い位置に余りが出る。

## 4. 変調方式

- **QPSK（副系 `SUB`）**: 副系 `SUB` はステレオ差分成分 $`S=(L-R)/2`$ と無関係（登録ステレオ主系の $`S`$ は階層16QAM）。各複素シンボルのI/Qに1 bitずつ（0を正、1を負）配置し、平均シンボルエネルギーを1に正規化する。
- **階層16QAM（主系）**: 各軸の符号bitを強い位置、半径側のGray符号bitを弱い位置に置く。登録プロファイルの階層パラメータは $`\alpha=5`$ で、各軸の絶対値は正規化前に $`\alpha`$ と $`\alpha+2`$。強い2位置を全シンボルに先に埋め、次に弱い2位置を埋める。通常16QAM（$`\alpha=1`$）は未登録。

### Y方式（QASK：高域専用シンボル）

Y帯域（登録プロファイルでは32 kHzで 2–4、4–8、8–16 kHzの $`k=2,3,4`$）の仮数を1係数につき1複素シンボルへ写像する。

- **送信写像**: 7 bit仮数 $`u`$ の最上位bit $`m`$ とそのパリティ $`c`$ を位相、下位6 bit $`L`$ を半径に割り当てる。
  - 象限番号 $`q=[0,1,3,2]_{2m+c}`$（Gray割当）、$`\theta=\pi/4+q\pi/2`$
  - 半径 $`r=[1+\delta(L-31.5)]/C`$、$`z=re^{i\theta}`$（$`\delta=2/105 = 0.08\times 7.5/31.5`$、$`C`$ は平均エネルギーを1にする正規化係数）
- **パリティと終端**: Y帯域の最上位bit列（係数順）に対する $`(133,171)_8`$ 符号の第2系列を位相に載せるため追加シンボルは不要。終端の12 bitだけはヘッダ側の強い位置に置く。
- **受信復号**:
  1. 位相のLLRから最上位bitとパリティを得て、終端bitと合わせてビタビ復号する。
  2. 訂正後の最上位bitとパリティで象限を決める。
  3. 受信点を象限の軸へ射影し、半径の段を1/2刻み（段6 bit＋小数1 bit＝7 bit。位相の最上位bit 1 bitと合わせて仮数8 bit）で推定し、誤差分散を求める。
- **CRCと占有帯域**: 最上位bitのうち $`k\ge 3`$ は高域CRC、それより低い帯域（$`k=2`$）は基本CRCの検査範囲に入る。Y対象はプロファイルで決まり（M系は $`M`$ のみ、B200Y/M700Yは $`M`$ と $`S`$）、非対象成分はデジタル部に残る。Y仮数がHaar係数部に入らないため強い位置の消費が減り、32 kHz系ではY無しの主系より占有帯域が小さくなる。

**Y系プロファイルのビット割当例**:

- **B200Y**: ステレオY主系。M・Sともに全幅 `(10,11,7,7,7)`（$`k=2,3,4`$ がY）。低中域MとSのデジタル部は階層16QAM（SだけQPSKにする仕組みはない）。
- **M700 / M700Y**: M700M/M700MYも階層16QAMで位相部・振幅部を係数ごとにそろえる。S割当は M700 が `(10,7,7,7,3)`、M700Y が `(10,11,7,7,7)`（$`k=2,3,4`$ がY）。

## 5. 受信、欠損データ、出力段

受信機の復調・復号処理は以下の順に進む。

1. **LLR算出**: シンボル（12 bit ADC出力）を小数22 bitの固定小数点に変換し、受信点と最寄り信号点との差から軸あたりの雑音分散をフレームごとに推定し、軸ごとに独立な max-log のLLR（符号つき8 bit整数）を得る。
2. **PRBS解除・ビタビ復号**: PRBSを戻し、ヘッダと係数のパリティをデータの軟値と合わせてビタビ復号し、上位 $`K`$ bitを訂正する。
3. **CRC検査と欠損判定**:
   - **基本CRC不一致**: フレーム全体を欠落とする（Y帯域の $`k=2`$ 最上位bitも基本CRC範囲のため、不一致時はフレーム欠落）。
   - **高域CRCのみ不一致**: H2/H1 のM/S係数を0にし、低中域のみ使用する。高域の融合用誤差分散は $`\infty`$ とし、他系統に正常な高域があればそちらを選ぶ。
4. **非保護bitの復元**: 上位 $`K`$ bitを除くHaar係数部のbitは、LLRからテーブルで引いた事後確率 $`p_1`$（Q15整数）を使い、期待値 $`E[u]=u_{\rm hard}+\sum(p_1-b_{\rm hard})2^{\rm pos}`$ と事後分散 $`\sum p_1(1-p_1)4^{\rm pos}`$ を計算して復元する。なお、CRCは非保護bitの誤りまで検出するものではない。

### 5.1 出力段のポストフィルタ

合成後の左右PCM（符号つき24 bit整数）を 48 kHz/int32 に変換する（実装：[postfilter.py](../gracefm/postfilter.py)）。再構成はDACに任せ、量子化区間への射影やブロックをまたぐ平滑化は行わない。

| 入力系 | 処理内容 | 群遅延 | 備考 |
|---|---|---|---|
| **48 kHz系** | フィルタを通さずそのまま32 bitへ拡張 | 0 | 乗算なし・遅延なし |
| **32 kHz系** | 3/2 再標本化（3倍ゼロ挿入 → 96 kHz FIR → 1/2間引き） | 96 kHzで47サンプル（約 0.49 ms） | 入力に1 bitガードを足し25 bit化 |

- **32 kHz系 FIRの仕様**: 96 kHz動作の95タップ線形位相FIR（Kaiser窓、カットオフ16 kHz）。係数は符号つき18 bit整数（Q16、`gracefm/tables.py`）。積和は48 bitアキュムレータに収まり、出力は四捨五入・右シフトして25 bitに飽和させる。短いフィルタのため16 kHz近くの鏡像は残る（設計減衰値は [評価結果 4.3節](EVALUATION.md#43-出力段ポストフィルタ32-khz--48-khzの鏡像減衰)）。
- **遅延モデルとシミュレーションツール**: FIRの群遅延は [timing.py](../gracefm/timing.py) の遅延モデルに別途加算する。`tools/sim/codec_wav.py` と `tools/sim/sim_link.py` は既定で出力段を通した 48 kHz/int32 WAV を出力し、`--no-postfilter` で元のサンプリング周波数の出力にできる。SNRやViSQOLの評価値は出力段の前で測る。

### 5.2 二系統融合と連続欠落の処理

#### 二系統融合（[fusion.py](../gracefm/fusion.py)）

- **時刻合わせと重み付け**: 副系は別周波数の独立ストリームとして同じ音声を同じ64サンプル格子で送る。受信機はブロック単位で時刻合わせし、M/Sの各Haar係数に推定誤差分散 $`R_A, R_B`$ の逆数で重み付けする：$w_A=(1/R_A)/(1/R_A+1/R_B)$（誤差分散は帯域ごと・半ブロックごとに見積もり、2係数以上の帯域は前半・後半で別値を使用）。
- **欠損・未送信の扱い**: 片系統だけ有効ならその系統を使い、未送信またはCRC消去した帯域は $`R=\infty`$ とする。副系の電力と帯域は主系と別に計上する。
- **`-L` プロファイルの融合**: 同じ重みを復号した係数へ直接適用してから 5/3 で合成する（[`fuse_overlapped`](../gracefm/fusion.py)）。両系統で同じフレームが欠けた場合は、そのブロックと前15・後16サンプルをPLCで埋める。

#### 設計コンセプト（冗長経路）

- 別局のB200系チャンネルの空き帯域に置く **SUB50M** を標準想定とする。別送信機・別周波数から来るため主系と電力を分け合わず、受信 $`C/N_0`$ も独立に扱う。
- チャンネルを増やさずに冗長経路を作ることが目的で、受信機は2周波数を同時受信する。SUB系は仮数を $`k=0\ldots2`$（0〜4 kHz）の低域だけに置き、H2/H1（$`k=3,4`$）は運ばない（見積もりとAWGN評価は [評価結果 4.4節](EVALUATION.md#44-冗長経路plciir切替ヘッダ救済の評価)）。

#### 連続欠落の補間（PLC：[plc.py](../gracefm/plc.py)）

- 有効な（系統、成分、帯域）の組が変わるブロック境界につなぎ処理は置かない。
- 両系統で同一区間が欠けた場合、直前最大128サンプルから次数16のLPCを推定して外挿する。
- **ゲイン包絡**: 最初の 10 ms はゲイン1を保持し、その後 20 ms で0へ減衰する。復帰時は4サンプルで予測値から受信値へクロスフェードする（比較評価は [評価結果 4.4節](EVALUATION.md#44-冗長経路plciir切替ヘッダ救済の評価)）。

#### 品質コード $`q`$ と出力の切り替え

出力の64サンプルブロックごとに品質コード $`q`$ を付与し（2系統時は良い方を採用）、$`q\in\{1,2\}`$ のブロックだけLPC外挿後の出力を因果IIRの出力へ切り替える。正常ブロックは切り替えないため通常の出力は変わらない。目的は高域の復元ではなく、誤って混入した高域成分の大きな誤差を抑えることにある（評価は [評価結果 4.4節](EVALUATION.md#44-冗長経路plciir切替ヘッダ救済の評価)）。

| 品質コード $`q`$ | 意味 | 切替先IIR |
|---:|---|---|
| **0** | 正常（基本CRC・高域CRCともに一致） | 切り替えなし（通常出力） |
| **1** | 高域欠落（高域CRC不一致、または高域なしプロファイル） | 因果IIRへ切り替え |
| **2** | 欠落（フレーム未着、または基本CRC不一致） | 因果IIRへ切り替え |

- **IIR仕様**: Butterworth 4次、カットオフ4 kHz、整数の直接形II転置。係数は符号つき18 bitのQ16固定（`b0`・`a1`・`a2` すべてQ16。実装：[iir.py](../gracefm/iir.py)、係数：[tables.py](../gracefm/tables.py)）。
- **切り替えと遅延**: ブロック先頭から `fs/1000` サンプル（32 kHzで32、48 kHzで48）の直線で切り替える。IIRの群遅延に揃えて出力全体を `ALT_DELAY` サンプル遅らせる（6節）。

#### ヘッダの救済（Chase型）

基本CRCが不一致のフレームに対し、ヘッダのうち信頼度 $`|{\rm soft}|`$ の低い7 bitから1個または2個を反転し、CRCが通る組を探す（`decoder.unpack_recovering`）。通常復号を含め最大29回まで試行し、最初にCRCが通った候補を採用して反転数を記録する（誤採用率と救済数は [評価結果 4.4節](EVALUATION.md#44-冗長経路plciir切替ヘッダ救済の評価)）。

### 5.3 RRCフィルタとゴースト用等化器

- **RRCフィルタ（[pulse.py](../tools/common/pulse.py)）**: 送信スペクトル評価ではシンボルを8倍にアップサンプルし、エネルギー正規化したルートレイズドコサイン（RRC）FIRで成形する。
  - B200 / B200Y（放送ステレオ主系）: ロールオフ $`\beta=0.10`$、長さ 32シンボル
  - その他の登録プロファイル: $`\beta=0.25`$、長さ 16シンボル
- **等価通信路モデル（[equalizer.py](../gracefm/equalizer.py)）**: 遅延反射波（ゴースト）によるシンボル間干渉を、送受信RRC整合フィルタ後のシンボル時刻標本でモデル化する（`matched_channel_taps`、`through_matched_channel`）。
```math
y[n]=\sum_{\ell}h[\ell]x[n-\ell]+v[n].
```
  - $`h[\ell]`$ は直接波・各反射波をRRC波形に通して得る複素タップ（非整数シンボル遅延も8倍標本RRC応答を補間して生成）。
  - 別周波数の副系では、同じ反射遅延 $`\tau`$ でも搬送波間隔 $`\Delta f`$ により反射位相が $`-2\pi\Delta f\tau`$ だけ変わる。
- **静的等化器の校正と設計**:
  - 受信側先頭100フレーム（32 kHzで0.2秒）を校正に使用（校正後のフレームは使わない）。既知の16シンボルプリアンブルと、フレーム番号追跡時のヘッダ符号bitの符号位置から通信路タップを最小二乗推定し（階層QAMヘッダの振幅bitは未知のため平均振幅を使用）、校正フレーム内の判定シンボルで2回更新する。
  - 推定タップと残差雑音電力から11タップ線形MMSE FIR等化器を設計する（先読み 0〜4シンボルから選択、目標タップ利得1に正規化後、残留ISI＋雑音増幅が最小の解を採用）。主系・副系は別々に等化してから復調・CRC・融合を行う。
  - [tests/test_equalizer.py](../tests/test_equalizer.py) では、B200Mの静的 5 µs・−10 dB 反射波、$`E_s/N_0=24`$ dB 条件で、校正後のシンボル誤差電力が等化前の 1/5 未満になることと将来フレーム非使用を検査する。
- **位置づけと制限**: 静的ゴーストの**緩和**を評価する任意の前処理であり、通常の `receive` 経路には自動接続されない（[eval_ghost.py](../tools/eval/eval_ghost.py) が `equalize_static` 経由で渡す）。搬送波・シンボル時刻取得は理想化しており、移動時の追従や実機除去率は未検証。送受信RRCと等化器先読み遅延は [timing.py](../gracefm/timing.py) で別途加算する。

## 6. 遅延、評価範囲、再現方法

### 遅延モデル（[timing.py](../gracefm/timing.py)）

| 条件 | 最小の一定再生遅延 | 32 kHz | 48 kHz | 備考 |
|---|---|---|---|---|
| **基本（Haar）** | $`2T_f`$ | 4 ms | 約 2.667 ms | 1フレーム蓄積＋1フレーム送信（処理・フィルタ遅延0の理想値） |
| **`-L`（LeGall 5/3）** | $`2T_f + 30/f_s`$ | 約 4.94 ms | 約 3.29 ms | 先読み30サンプル加算 |
| **IIR切替整合（`ALT_DELAY`）** | `ALT_DELAY` サンプル | 3サンプル | 5サンプル | 約 0.09〜0.10 ms（[iir.py](../gracefm/iir.py)） |

- 二系統融合でも格子が同じため基本基準は同じ。実機ではこれにRRC、等化器先読み、符号化・復号、ADC/DAC、同期取得、出力バッファを加える（[timing.py](../gracefm/timing.py) はこれらを個別に加算する計算モデルであり、実機遅延の実測ではない）。
- 参照実装の `-L` はストリーム全体を一括変換するオフライン処理だが、因果的に動かせることは `tests/test_legall.py` で確認済み（フレームが先読みより先に依存しないこと、出力単位が次フレームに依存しないこと）。
